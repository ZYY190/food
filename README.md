## 项目概要

以微信小程序为载体，整合食堂窗口、周边商铺、路边小摊三类校园餐饮供给，用**大模型智能对话**解决"今天吃什么"的选择困难，用**跨平台比价与省钱榜单**呈现性价比，并打通浏览—决策—比价—评价—加购下单的完整闭环。
